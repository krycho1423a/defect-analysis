From a spike to a cause

Page 2 is the analyst workflow after monitoring: isolate a dimensional shift, join quality events with process stops, and detect repeating contamination cycles instead of treating each NG as independent.

VCT — stack, equipment and searching IDs redacted. Charts keep the diagnostic logic visible.

Dimensional diagnostics (VCT)

Not every NG is a visual defect. This view decomposes alignment into measured terms (AC, previous/current CPOS, stacker shift) and a result (CA) against a spec limit. The formula is shown on screen so a judgement is auditable.

Pareto-style bars split cause codes; line charts show whether a shift is a step change or noise. That is standard process-control thinking: separate special cause from common cause before changing the machine.

Lami correlation — remarks, cell IDs and line names redacted.

Stop events versus quality

Downtime and defects share a clock. Flags (sensor / NG conditions) sit on a Gantt-like lane; defect dots and hourly bars sit below. The question is whether quality collapses during a stop, after a restart, or independently.

Duration buckets (0–5 s … 60+ s) turn a long event log into a distribution. That is more useful for a standup than a raw list of timestamps: you can say what share of loss is long stops versus chatter.

Roll contamination — production-line names redacted. Cycle types and spatial bands remain as method.

Repeating contamination cycles

If a defect band returns every N minutes, it is probably a roller or merge event, not a random particle. This module groups time windows, tags cycle type (align / merge / lami), and shows the matching spatial signature.

The daily stacked bars are a simple seasonality check: which days the cycle is active. For an analyst this is pattern detection on event data, then confirmation on the image — hypothesis, then evidence.
